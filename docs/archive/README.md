# Research and validation archive

These records preserve the development history. Revision names identify the
images that were tested; they are not current product editions or a roadmap.
Use the [operation guide](../usage.md) for the supported installation path.

- [Latest-release installation check](latest-release-tests.md) — the permanent download link, fresh install and repeat import.
- [Runtime validation](runtime-tests.md) — forwarding, recovery, diagnostics and storage measurements.
- [RouterOS installer validation](routeros-tests.md) — installation, updates, rollback and interruption testing.
- [NAT64 and Psiphon experiments](carrier-experiments.md) — alternative WARP paths investigated and excluded from the product.
- [Historical computer-side installer](computer-installer.md) — the earlier administration approach, superseded by direct RouterOS installation.
- [Runtime evidence](evidence/r14.json) and [installer evidence](evidence/routeros-native.json) — sanitized measurements.

The initial v1 release reuses the tested container unchanged. Its historical
image labels remain for traceability. Earlier size-reduction and alternative
edition ideas in these records are historical, not planned product features.

Raw router configuration, registrations, VM disks and private diagnostics are
excluded from this repository and its release assets.
